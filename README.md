## ✨ Features
- 🎥 배경 메인 영상이 **실시간 날씨에 따라 변화**
- 💬 사용자 간 실시간 채팅 기능
- 📍 현재 위치 기반 **실시간 날씨 정보 제공**
- 🔗 게시글 **외부 공유 및 클립보드 복사** 기능
- 📝 게시글 작성, 수정, 삭제 (CRUD)
- #️⃣ 게시글 태그 및 **지도 첨부 기능**
- ❤️ 게시글 좋아요 및 **댓글/답글 알림**
- 🔍 검색, 페이징, 내가 쓴 글/댓글 모아보기
- 🔐 **OAuth 로그인** (네이버, 구글)
- 📧 회원가입 시 이메일 인증 및 유효성 검사
- 🛠 프로필 수정: 기본 이미지 선택 or 직접 업로드 / 닉네임 변경
